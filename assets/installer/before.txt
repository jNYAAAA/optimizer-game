Optimizer Game — приложение для Windows 10/11.

Возможности:
• характеристики ПК и температура всех комплектующих (встроенный монитор датчиков);
• драйверы: версии, проверка обновлений, установка драйверов NVIDIA;
• оптимизация: очистка файлов, автозагрузка, службы, память, 44+ твика;
• игры: профили настроек и разделы NVIDIA/Windows для CS2, Dota 2, Apex Legends,
  PUBG, Squad, DayZ, Grand Theft Auto V.

Приложение работает с правами администратора: при запуске появится запрос UAC.

Все изменения обратимы — резервные копии хранятся в %APPDATA%\OptimizerGame.
