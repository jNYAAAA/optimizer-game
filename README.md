# Optimizer Game

Приложение для Windows: при запуске показывает текущие характеристики ПК, а
также позволяет аккуратно оптимизировать систему с возможностью отката.

Интерфейс на **Python + PySide6 (Qt)**.

## Возможности

### Стартовый экран «Характеристики ПК»
- **Процессор**: модель, ядра/потоки, макс. частота, сокет, кэш L2/L3, разрядность.
- **Оперативная память**: объём, тип (DDR4/DDR5), частота, форм-фактор, список модулей.
- **Видеокарта**: модель, объём видеопамяти, версия и дата драйвера, разрешение.
- **Накопители**: модель, объём, тип (SSD/HDD), шина (NVMe/SATA), использование разделов.
- **ОС**: название, версия и сборка, разрядность, дата установки, имя ПК и пользователя.
- **Материнская плата и BIOS**: производитель, модель, версия и дата BIOS.
- Загрузка **CPU и RAM** обновляется в реальном времени, плюс время работы системы.
- **Датчики и температура** — отдельный блок: GPU через `nvidia-smi`, накопители через
  SMART (в т.ч. ATA-атрибуты 194/190), CPU/вентиляторы и прочее через
  LibreHardwareMonitor / OpenHardwareMonitor, плюс ACPI-термозоны. Значения обновляются
  автоматически. В блоке есть кнопка запуска/скачивания LibreHardwareMonitor (он даёт
  температуру CPU и обороты вентиляторов через WMI) и кнопка повышения прав администратора
  (нужны для части датчиков).
- **Светлая и тёмная темы** — переключаются иконкой луны в правом верхнем углу, выбор сохраняется.

### Модули оптимизации
Первые четыре модуля объединены в одну страницу **«Оптимизация»** с переключателем
разделов (каждый раздел по-прежнему выбирается отдельно).

- **Очистка файлов** — временные файлы пользователя и системы, кэш обновлений Windows,
  Prefetch, аварийные дампы, кэш эскизов, кэши браузеров (Chrome, Edge, Brave, Firefox),
  корзина. Перед удалением выполняется сканирование с подсчётом объёма.
- **Автозагрузка** — просмотр и отключение записей (реестр `Run` и папки «Автозагрузка»).
  Отключённые записи сохраняются в папке данных и включаются обратно одним нажатием.
- **Службы Windows** — поиск, фильтр по рекомендуемым к отключению, смена типа запуска,
  запуск/остановка.
- **Память** — обрезка рабочих наборов процессов и очистка списка ожидания (standby list).
- **Твики реестра и сети** — телеметрия и задачи телеметрии, Xbox Game Bar и игровой режим,
  ускорение мыши, службы Xbox, Cortana и поиск Bing, виджеты, кнопка чата, прозрачность,
  тёмная тема Windows, расширения файлов, рекламный идентификатор, советы и предложения,
  запросы отзывов, сетевой троттлинг, алгоритм Нейгла, энерготроттлинг, ускорение выключения,
  гибернация, службы (SysMain, Windows Search, отчёты об ошибках) и другое. Оригинальные
  значения сохраняются, любой твик можно откатить.

## Требования

- Windows 10/11
- Python 3.10+ (для запуска из исходников)
- Права администратора — для части функций (службы, записи в `HKLM`, Prefetch, корзина,
  очистка standby-списка). Приложение работает и без них, но с ограничениями.

## Установка и запуск

```powershell
# 1. Создать виртуальное окружение
python -m venv .venv
.\.venv\Scripts\Activate.ps1

# 2. Установить зависимости
python -m pip install -r requirements.txt

# 3. Запустить
python main.py
```

Чтобы сразу получить права администратора, запустите терминал от имени
администратора либо нажмите «Запустить от имени администратора» в приложении
(страница «Настройки» или баннер на любой странице).

## Структура проекта

```
main.py                     точка входа
app/
  admin.py                  проверка и получение прав администратора
  config.py                 константы и папка данных приложения
  utils.py                  запуск команд, PowerShell, форматирование
  core/
    hardware.py             сбор характеристик ПК (CIM + psutil)
    sensors.py              сбор температур комплектующих
    cleanup.py              сканирование и очистка файлов
    startup.py              управление автозагрузкой
    services.py             управление службами Windows
    memory.py               оптимизация оперативной памяти
    tweaks.py               твики реестра/сети с откатом
    registry.py             обёртка над winreg
    workers.py              фоновые задачи (QThreadPool)
  ui/
    main_window.py          главное окно и навигация
    theme.py                тёмная тема (QSS)
    widgets.py              переиспользуемые виджеты
    pages/                  страницы: дашборд, оптимизация (очистка/автозагрузка/
                            службы/память), твики, настройки
```

## Данные приложения

Все резервные копии хранятся в `%APPDATA%\OptimizerGame`:

- `disabled_startup.json` — отключённые записи автозагрузки;
- `tweak_backup.json` — исходные значения изменённых твиков;
- `settings.json` — настройки.

## Безопасность

- Удаление файлов затрагивает только перечисленные кэши и временные папки; занятые файлы
  пропускаются.
- Изменения автозагрузки и твиков обратимы: перед изменением сохраняются исходные данные.
- Очистка standby-списка и отключение служб могут временно замедлить систему — применяйте
  осознанно.

## Сборка в один .exe (необязательно)

```powershell
python -m pip install pyinstaller
pyinstaller --noconfirm --windowed --name OptimizerGame --collect-all PySide6 main.py
```

Готовый файл появится в `dist/OptimizerGame/`.
