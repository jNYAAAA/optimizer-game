# Optimizer Game

Приложение для Windows: при запуске показывает текущие характеристики ПК, а
также позволяет аккуратно оптимизировать систему с возможностью отката.

Интерфейс на **Python + PySide6 (Qt)**.

## Возможности

### Стартовый экран «Характеристики ПК»
- **Процессор**: модель, ядра/потоки, макс. частота, сокет, кэш L2/L3, разрядность.
- **Оперативная память**: объём, тип (DDR4/DDR5), частота, форм-фактор, список модулей.
- **Видеокарта**: модель, объём видеопамяти, версия и дата драйвера, а также **все
  подключённые мониторы** — разрешение, частота обновления, модель и какой из них основной.
- **Накопители**: модель, объём, тип (SSD/HDD), шина (NVMe/SATA), использование разделов.
- **ОС**: название, версия и сборка, разрядность, дата установки, имя ПК и пользователя.
- **Материнская плата и BIOS**: производитель, модель, версия и дата BIOS.
- Загрузка **CPU и RAM** обновляется в реальном времени, плюс время работы системы.
- **Датчики и температура** — блок с температурами CPU, GPU, накопителей, чипсета, модулей
  памяти и оборотами вентиляторов. Внутрь встроен **LibreHardwareMonitor** (компонент
  `SensorHelper` на базе LibreHardwareMonitorLib, лицензия MPL-2.0), поэтому данные
  доступны сразу, без установки сторонних программ. Значения обновляются автоматически.
  Резервные источники — `nvidia-smi`, SMART и ACPI-термозоны.
- **Вкладка «Оптимизация игр»** — под-вкладки по играм с логотипами и профилями настроек
  «максимум FPS без потери качества»: **Counter-Strike 2, Dota 2, Apex Legends,
  PUBG: Battlegrounds**. Настройки применяются в один клик, исходные файлы сохраняются.
- **Светлая и тёмная темы в стиле Windows 11 (Fluent)** — переключаются иконкой в правом
  верхнем углу, выбор сохраняется.
- **Анимированный экран загрузки** и собственная иконка приложения.
- **Вкладка «Драйверы»** — текущие версии драйверов устройств (видео, сеть, звук, чипсет,
  диски, USB, Bluetooth и др.), проверка обновлений через Windows Update и официальные сайты
  производителей, установка драйверов NVIDIA, а также определение **материнской платы**
  (со ссылкой на её драйверы) и **устройств без драйверов** (со ссылкой на каталог Microsoft).

### Модули оптимизации
Первые четыре модуля объединены в одну страницу **«Оптимизация»** с переключателем
разделов (каждый раздел по-прежнему выбирается отдельно).

- **Очистка файлов** — временные файлы пользователя и системы, кэш обновлений Windows,
  Prefetch, аварийные дампы, кэш эскизов, кэши браузеров (Chrome, Edge, Brave, Firefox),
  корзина. Перед удалением выполняется сканирование с подсчётом объёма.
- **Автозагрузка** — просмотр и отключение записей (реестр `Run` и папки «Автозагрузка»).
  Отключённые записи сохраняются в папке данных и включаются обратно одним нажатием.
- **Службы Windows** — поиск, фильтр по рекомендуемым к отключению, смена типа запуска,
  запуск/остановка.
- **Память** — обрезка рабочих наборов процессов и очистка списка ожидания (standby list).
- **Твики реестра, сети и служб** — всего **61 твик**: телеметрия и её задачи, Xbox Game Bar
  и игровой режим, службы Xbox, Cortana и поиск Bing, виджеты, кнопка чата, прозрачность,
  тёмная тема Windows, расширения файлов, рекламный идентификатор, советы и предложения,
  запросы отзывов, сетевой троттлинг, алгоритм Нейгла, энерготроттлинг, ускорение выключения,
  гибернация, **протоколы** (SMBv1, NetBIOS over TCP/IP, Teredo/6to4/ISATAP),
  **службы** (Print Spooler, удалённый рабочий стол, WinRM, Bluetooth, биометрия, AllJoyn,
  ICS, вторичный вход, планшетный ввод и др.), Prefetch/SuperFetch, приоритет активных
  программ. Оригинальные значения сохраняются, любой твик можно откатить. Твики
  сгруппированы по вкладкам: **Скорость, Приватность, Интерфейс, Сеть, Службы, Игры**
  (плюс «Все»).

## Требования

- Windows 10/11
- Python 3.10+ (для запуска из исходников)

Приложение запускается с правами администратора автоматически: при старте запрашивается
UAC и создаётся копия с повышенными правами.

## Установка и запуск

```powershell
# 1. Создать виртуальное окружение
python -m venv .venv
.\.venv\Scripts\Activate.ps1

# 2. Установить зависимости
python -m pip install -r requirements.txt

# 3. Запустить
python main.py
```

### Быстрый запуск (файлы .bat)
- `setup.bat` — один раз: создаёт `.venv` и устанавливает зависимости.
- `run.bat` — запускает приложение (без окна консоли). При старте запросит права
  администратора.

Совет: сделайте ярлык на `run.bat` — правой кнопкой мыши → «Отправить» → «Рабочий стол».

## Структура проекта

```
main.py                     точка входа
app/
  admin.py                  автозапуск с правами администратора (UAC)
  config.py                 константы и папка данных приложения
  utils.py                  запуск команд, PowerShell, форматирование
  core/
    hardware.py             сбор характеристик ПК (CIM + psutil)
    sensors.py              сбор температур комплектующих
    cleanup.py              сканирование и очистка файлов
    startup.py              управление автозагрузкой
    services.py             управление службами Windows
    memory.py               оптимизация оперативной памяти
    tweaks.py               твики реестра/сети с откатом
    registry.py             обёртка над winreg
    workers.py              фоновые задачи (QThreadPool)
  ui/
    main_window.py          главное окно и навигация
    theme.py                тёмная тема (QSS)
    widgets.py              переиспользуемые виджеты
    pages/                  страницы: дашборд, оптимизация (очистка/автозагрузка/
                            службы/память), твики, настройки
```

## Данные приложения

Все резервные копии хранятся в `%APPDATA%\OptimizerGame`:

- `disabled_startup.json` — отключённые записи автозагрузки;
- `tweak_backup.json` — исходные значения изменённых твиков;
- `settings.json` — настройки.

## Безопасность

- Удаление файлов затрагивает только перечисленные кэши и временные папки; занятые файлы
  пропускаются.
- Изменения автозагрузки и твиков обратимы: перед изменением сохраняются исходные данные.
- Очистка standby-списка и отключение служб могут временно замедлить систему — применяйте
  осознанно.

## Сборка .exe

Готовый файл собирается одним скриптом:

```powershell
build.bat
```

Он устанавливает PyInstaller, генерирует иконку (`assets/make_icon.py`) и собирает
`dist\OptimizerGame.exe` (один файл) по спецификации `OptimizerGame.spec`.

Вручную:

```powershell
python -m pip install pyinstaller pillow
python assets/make_icon.py
pyinstaller --noconfirm --clean OptimizerGame.spec
```

При запуске показывается анимированный экран загрузки, а иконка `assets/icon.ico`
используется для окна и самого `.exe`.
